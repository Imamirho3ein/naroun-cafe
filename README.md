# کافه نارون — Naroun Cafe

یه سایت که مثل بقیه نیست. 🎉

یک وبسایت مدرن و ریسپانسیو برای **کافه نارون**، ساخته شده با React + Vite + Tailwind CSS و Framer Motion.

## بخش‌ها

- **Hero** — شعار اصلی و CTA
- **Intro** — معرفی کافه
- **Pastries** — شیرینی‌هایی که همینجا پخته می‌شوند (تعاملی)
- **Menu** — امروز دلتان چه می‌خواهد؟ (نوشیدنی، غذا و دسر، چای)
- **Beans** — دانه‌هایی که هر هفته برشته می‌شوند
- **Footer** — اطلاعات تماس و شبکه‌های اجتماعی
- **Chat Widget** — «Messages Now» گوشه صفحه

## تکنولوژی‌ها

- React 19
- Vite 8
- Tailwind CSS 3
- Framer Motion

## اجرا در محیط توسعه

```bash
npm install
npm run dev
```

## بیلد برای پروداکشن

```bash
npm run build
npm run preview
```
